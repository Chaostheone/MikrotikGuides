// use-case reference

Use Guide 1 — CAP Client

  • Adding a remote AP to existing CAPsMAN
  • Device has been factory reset
  • No local DHCP needed on this AP
  • Controller already reachable on network

Use Guide 2 — Server Setup

  • Deploying a brand-new CAPsMAN controller
  • Fresh device with no prior config
  • Need to create bridges + DHCP from scratch
  • wlan1 also used as local CAP

Use Guide 3 — Update

  • Existing server needs SSID / password change
  • Adding CAPsMAN to already-configured unit
  • Changing channel or TX power
  • Replacing failed server with same config

Pre-Deploy Checklist

  • Back up device before any changes
  • Fill all <PLACEHOLDER> values
  • Verify bridge exists before Guide 3
  • Factory reset before Guides 1 & 2
// quick cli reference
routeros — common commands across all guides 
# Enable CAPsMAN Manager
/caps-man manager set enabled=yes

# Create CAPsMAN channel (2.4 GHz)
/caps-man channel add band=2ghz-b/g/n name=2.4 control-channel-width=20mhz \
  frequency=2412,2417,2422,2437,2462 reselect-interval=6h

# Register local wlan1 as CAP (server — loopback)
/interface wireless cap set enabled=yes interfaces=wlan1 caps-man-addresses=127.0.0.1

# Register remote CAP pointing to controller IP
/interface wireless cap set enabled=yes interfaces=wlan1 \
  discovery-interfaces=Internal caps-man-addresses=<CAPSMAN_SERVER_IP>

# Add all ethernet ports to a bridge automatically
:foreach i in=[/interface ethernet find] do={
  /interface bridge port add bridge=Internal interface=$i
}

# Set system identity
/system identity set name="CP_<SITE_NAME>"
